26.3 重点功能：系统更新（OTA）
------------------------------
· 系统更新（OTA）：开始 → 设置 → Windows 更新，或程序 → 系统更新。
  客户端会从 GitHub Releases 的 latest.json 检查新版本，显示更新说明，
  下载并校验更新包后写入备用插槽，重启即进入新系统。
· 共享超级分区 A/B：安装时不再建立单一根分区，而是建立一个
  WIN95SUPER 超级分区，内含 slots/a、slots/b、ota/state.json 与 cache。
  两个插槽共享同一分区的剩余空间，更新只写当前未运行的插槽。
· 文件级快照：更新前用硬链接克隆当前插槽，未改动的文件共享磁盘块；
  用户文档、下载、安装的软件与 Arch 子系统都会保留。
· 试用与自动回退：新插槽首次启动处于试用状态，桌面成功启动数秒后
  自动确认；连续两次启动失败时，引导程序会回退到旧插槽。
· 版本文件：/etc/win95-version 记录 VERSION、BUILD 与 SLOT_LAYOUT；
  系统更新窗口显示当前版本与运行插槽。
· GitHub 发布约定：每个版本发布时，除安装镜像外还需附带
  win95-ota-<版本>-aarch64.tar.gz、对应的 .sha256 与 latest.json；
  版本号按“26.x → 27.0”递增，不会把主版本更新伪装成 26.y。
· 本机版本为 26.5：26.5 的安装镜像、更新包、SHA256 与 latest.json 已随
  Release 全部上传；后续 27.0 发布后，打开“系统更新”即可检查、下载并升级。
· 国内网络：客户端会并行探测 GitHub 直连与公共加速镜像，
  清单取最先响应的源，下载按测速顺序自动换源并支持续传；
  可在 /etc/win95-ota.conf 中添加 MIRROR、改 MANIFEST_URL，
  或写 DIRECT=0 跳过 GitHub 直连。修改后无需重启。

鼠标右键菜单
------------
在桌面、图标、窗口标题栏和任务栏上单击右键，都会弹出对应的菜单：
· 桌面空白处：排列图标、刷新、新建、属性（打开显示属性）。
· 桌面图标：打开、资源管理器、重命名、删除、属性。
  回收站图标另有“清空回收站”。
  “我的电脑”等系统图标不能重命名或删除。
· 窗口标题栏：还原、移动、大小、最小化、最大化、关闭。
  也可以按 Alt+Space 打开这个窗口菜单。
· 任务栏：开始按钮、任务按钮、时钟、托盘和空白区域各有菜单。
  空白区域可以层叠窗口、横向平铺、纵向平铺或最小化所有窗口。
菜单支持键盘操作：方向键选择，Enter 确认，Esc 关闭。

桌面文件操作
------------
桌面会显示 /root/桌面 中的真实文件和文件夹，双击即可打开。
· 新建：右键桌面 → 新建 → 文件夹 / 文本文档。
· 重命名：选中图标后按 F2，或右键选择“重命名”。
· 删除：选中后按 Delete，文件会被移到 /tmp/.trash 回收站。
· 属性：查看文件路径、类型、大小和修改时间。
· 拖放：在文件管理器中按住文件拖到回收站图标、回收站窗口，
  或拖到桌面空白处。拖到回收站会删除文件，拖到桌面会创建
  名为“原名 - 快捷方式”的快捷方式。
· 排列：拖动图标可调整位置；右键桌面可自动排列、对齐到网格、
  按名称排序或按类型排序。
· 刷新：按 F5 或右键选择“刷新”，重新读取桌面文件夹。
桌面快捷键：方向键选择图标，Enter 打开，F2 重命名，Delete 删除，
Ctrl+N 新建文件夹，Esc 取消选择。

系统托盘、显示属性与屏保
------------------------
任务栏右下角显示 CPU 与 RAM 的实时百分比，数据来自
/proc/stat 和 /proc/meminfo，每秒刷新一次。
CPU/RAM 左侧还有网络状态指示灯：绿色表示能连接外网，
红色表示断网，灰色表示正在检测。系统每 12 秒检测一次；
右键托盘选择“网络状态”可以查看详情。

当截图保存、下载完成，或 X11 代理中有事件时，任务栏右下角会
弹出黄色气泡提示，约 8 秒后自动消失；点击气泡右侧的 × 可关闭。

右键桌面选择“属性”，或打开“开始 → 设置 → 显示属性”，可以：
· 在“背景”页选择经典青色、纯青色、海洋蓝、云彩、午夜星空
  或石板灰，右侧显示器会实时预览，确定后立即应用到桌面。
· 在“屏幕保护程序”页选择“无”“变幻线”“星空”或“飞行窗口”，
  并把等待时间设为 1 到 120 分钟。点击“预览”可全屏查看，
  移动鼠标或按任意键返回。设置保存在
  /root/.config/win95/desktop.json，下次启动仍然有效。
  “飞行窗口”是满屏的小 Win95 窗口从中心向四周飞散的 3D 效果。

运行与查找
----------
开始菜单中新增了两个实用工具：
· 运行：输入 calc、notepad、cmd、explorer、iexplore、
  pkgman、control 等命令，或输入文件路径、文件夹路径、网址。
  例如输入 example.com 会直接用浏览器打开。按 ↑ / ↓ 可以
  调出最近使用过的命令；点击“浏览”可以选择文件。
· 查找：在“名称”中输入关键字（支持 * 和 ? 通配符），
  选择搜索范围和是否包含子文件夹/隐藏文件，点击“开始查找”。
  结果会在后台逐步列出，可以随时停止；双击结果即可打开文件
  或进入文件夹。

清空回收站
----------
删除的文件和桌面项目会移到 /tmp/.trash。右键回收站图标选择
“清空回收站”，或者在回收站窗口中打开“文件 → 清空回收站”，
确认后即可永久删除其中的全部项目。

纸牌
----
开始 → 程序 → 纸牌，规则与 Windows 经典纸牌（Klondike）相同：
· 右上角四个接龙堆从 A 到 K 按花色收牌。
· 下方七列按红黑交替、点数递减堆叠；空列只能放 K。
· 点左上角牌堆发三张牌，发完后点空牌堆重新发牌。
· 拖动牌可以移动；双击一张顶牌会自动送到接龙堆。
· “游戏 → 撤销”（Ctrl+Z）可回退，“发新牌”（F2）重开一局。
· 公平发牌：每次开局都会保证至少有一步可走（含首轮翻牌），
  不会出现无解的“地狱开局”。
· 状态栏显示得分、时间和步数，全部收完会弹出胜利提示。

实用工具
--------
· 截屏：按 Print Screen，或“开始 → 设置 → 截屏”。当前画面会同时
  保存为 /root/下载/截图-年月日-时分秒.png 和同名 .bmp（24 位 BMP），
  并弹出提示气泡。请先点一下 UTM 窗口，确保按键送进虚拟机。
· 图片查看器：开始 → 程序 → 图片查看器，或在文件管理器中双击
  .png / .bmp 文件。滚轮缩放，拖动图片平移。
· 画图：文件 → 打开（Ctrl+O）可载入 PNG/BMP，大图会自动缩小到
  窗口内并居中显示；保存仍输出 24 位 BMP。
· 图形化下载器：开始 → 程序 → 图形化下载器。输入 http:// 或
  https:// 地址（省略协议会自动补 https://），点“开始下载”。
  文件保存在 /root/下载，显示进度、已下载大小和速度；可随时取消。
  下载完成后会弹出气泡提示。
· PC 喇叭提示音：开机与错误对话框会尝试通过控制台响铃。
  UTM / Apple 虚拟化不一定提供 PC 喇叭，听不到声音属于正常现象。

屏幕键盘与 PowerShell
---------------------
· 屏幕键盘：Ctrl+Alt+K，或“开始 → 程序 → 屏幕键盘”。点击键位即可
  输入字母、数字、符号和常用控制键；再次按快捷键或关闭窗口即可收起。
· Windows PowerShell：开始 → 程序 → Windows PowerShell。支持
  Get-ChildItem、Get-Date、Write-Output、Select-Object 等常用 cmdlet
  和管道；未识别的命令交给 /bin/sh 执行。外部命令运行在真实伪终端上：
  输出实时显示，stdin 保持连接，read、ssh、apk/pacman 确认提示等交互
  程序可以直接操作；Ctrl+C 中断当前命令。默认没有运行时限，需要时
  执行 $PSCommandTimeout = 300（秒）或在启动前设置 WIN95_PS_TIMEOUT。
  输入 exit 退出。
· PowerShell ISE：开始 → 程序 → Windows PowerShell ISE。上部编辑脚本，
  下部显示输出；F5 运行，Esc 停止，Ctrl+S 保存，Ctrl+O 打开。
· 浏览器 JavaScript：首次打开浏览器会自动安装本地运行时依赖包，
  完成后可运行页面中的 ECMAScript 5.1 脚本。若系统缺少 CA 证书，
  启动过程会尝试通过 apk 联网补装；离线时只显示提示，本地页面和
  脚本不受影响。安装失败时页面会显示错误信息，重新打开会再次尝试。

方块世界 95
-----------
开始 → 程序 → 方块世界 95。这是一个 2D 沙盒游戏：
· A / D 或左右方向键移动，W / ↑ / 空格跳跃。
· 左键长按挖掘方块，右键放置方块，滚轮或 1–9 选择物品栏。
· 合成：按 E 打开合成面板。木头→木板、木板→工作台等基础配方随时可合成；
  玻璃、砖块等高级配方需要站在放置的工作台旁。↑↓ 选择、Enter/合成按钮确认。
· 3D 立体视角：按 V 切换。方块会以带亮顶面、暗侧面的立体立方体绘制，
  再按 V 切回平面视角；挖掘与放置操作不受影响。
· 动画与音效：挖掘碎屑、拾取飘字、昼夜与云都会动；挖掘/放置/跳跃/合成
  会通过 PC 喇叭发出不同音调（UTM / Apple 虚拟化可能无声，属正常）。
· 天色会随昼夜变化；进度自动保存在
  /root/文档/方块世界存档.json，也可用“游戏”菜单手动保存或读取。
· 它只读写自己的存档文件，不会修改系统设置或磁盘分区。

视觉整活与光敏性癫痫警告
------------------------
“开始 → 程序 → 视觉整活：苏尔科…”是一个无害的全屏玩笑：
· 开始前会显示光敏性癫痫与“精神污染”警告，必须先点确认才会运行。
  对闪烁敏感者请选择“温和模式”（无闪烁、无反色）；正常模式含每秒 1 次
  全屏反色与快速闪烁，光敏性癫痫患者请勿观看正常模式。
· 确认后约 30 秒内无法中途退出（没有中止按钮，Esc 无效），只能等待自动结束。
· 特效是覆盖在桌面图层之上的一层动画，并不替换真实桌面：桌面和窗口仍在
  下面正常运行，点击或按键会短暂显现真实桌面（例如按原来的开始位置仍会
  弹出开始菜单），随后又被特效覆盖；鼠标指针始终在最上层。
· 先播放假的 NTFS 格式化，随后进入六阶段“苏尔科”虚构病毒动画：
  桌面跳舞、绿色横纹、形状爆炸、中心宣告、吞噬漩涡、
  图标大乱斗，最后是假蓝屏。全程带有“仅视觉演示！！不破坏系统”的横幅。
· 中途会随机弹出显示 DEAD 的黑色终端窗口和“你中了苏尔科病毒！”的错误
  对话框，它们都会自己关闭，不会真的影响系统。
· 漩涡会把桌面图标、窗口和虚构的 SULKO.SYS 图标旋转着吸向中心；
  图标乱斗的最后约 1 秒画面会“卡死”，然后自动进入假蓝屏。
· 不调用 mkfs、fdisk、dd，不打开 /dev，不写入分区表，不删除或移动文件。
· 约 30 秒后自动结束，并再次说明所有数据完好。
“死手系统”的授权页也有同样的光敏性癫痫提示，倒计时闪红约每秒 1.5 次。

首次启动欢迎与许可协议
----------------------
第一次进入桌面时会弹出“欢迎使用 Windows 95 Linux”窗口，内含可滚动的
Apache License 2.0 全文：
· 滚轮 / 滚动条 / PageUp / PageDown 阅读协议。
· 点“接受并继续(A)”或按 Enter/A：接受协议并保存标记，随后打开欢迎说明；
  之后启动不会再弹出本协议。
· 点“拒绝(R)”或按 Esc：不接受，下次启动仍会显示本协议。
接受标记保存在 /root/.config/win95/desktop.json（eula_accepted 字段）。

剪贴板
------
记事本与终端共用同一个系统剪贴板：
· 记事本：Ctrl+C 复制、Ctrl+X 剪切、Ctrl+V 粘贴，
  也可以按住鼠标拖动选择文本。
· 终端：Ctrl+Shift+C 复制、Ctrl+Shift+V 粘贴。
· X11 代理中的程序与 Win95 之间的剪贴板通过 /run/win95-clipboard 同步；
  代理启动的会话会自动运行剪贴板守护进程 win95-clipd。

软件安装与快捷方式
------------------
本系统基于 Alpine Linux（musl），自带 apk 包管理器。
默认使用清华大学 TUNA 镜像（mirrors.tuna.tsinghua.edu.cn）。
打开“开始 → 程序 → 软件包管理器”，先点“刷新”下载软件源索引，
然后输入英文名称搜索并安装。也可以在终端中直接使用：
    apk update
    apk add 软件名
安装完成后，若软件带有图形桌面入口，系统会自动在 /root/桌面
生成快捷方式，双击即可使用（X11 程序会在嵌套代理窗口中启动）。
卸载软件时，自动生成的快捷方式也会一并删除。
注意：Arch/glibc 的软件包不能安装在本系统上。
若镜像不可用，编辑 /etc/apk/repositories 可切换回官方源。
画图可以打开 /root/图片 中的 PNG/BMP 文件，保存的 BMP 也默认放在
/root/图片 文件夹。

网络
----
系统启动时会通过 DHCP 自动获取地址。
如果网络不可用，请检查虚拟机的网卡设置。
浏览器下载的文件保存在 /root/下载 文件夹。

睡眠
----
打开“开始 → 睡眠(S)…”，确认后桌面会先显示深蓝色的睡眠画面，
再让系统进入睡眠以节省电力。按任意键或移动鼠标即可唤醒，
醒来后会提示“系统已从睡眠中唤醒”。
系统会优先使用内核的 freeze（suspend-to-idle）状态，其次尝试
mem（挂起到内存）。是否真正暂停虚拟机取决于 UTM / Apple 虚拟化
对系统睡眠的支持；如果当前内核或虚拟机不支持，系统会弹出错误
提示并留在桌面，不会影响正在编辑的文件。
安装程序运行期间不能进入睡眠。

关机、重启与注销
----------------
开始菜单底部的三个选项都会先弹出 Win95 风格的确认框：
· 关闭计算机：安全关机（poweroff）。
· 重新启动：重启（reboot）。
· 注销：结束当前桌面并返回文本登录提示，按回车可重新进入桌面。

X11 嵌套代理
------------
桌面上的“XFCE 终端”“Firefox”“X11 代理”图标，以及“开始 → 程序”
中的对应条目，会在不结束 Win95 桌面的情况下运行 X11 程序：
· 后台启动虚拟显示 Xvfb :1（800×600×24），不切换控制台。
· 代理协程每隔约 110 毫秒用 XGetImage 抓取 :1 的画面并绘制到窗口；
  鼠标、滚轮和键盘通过 XTest 回送，右键会补发 button 3。
· 首次使用若缺少 Xvfb、Firefox 或 xfce4-terminal，会询问并运行
  win95-x11-setup 安装；进度显示在“安装进度”窗口，完成后自动启动。
· 代理窗口工具栏提供“终端”“浏览器”“重连”；Xvfb 异常退出后点
  “重连”会清理失效的 /tmp/.X1-lock 并重启虚拟显示。
· 日志：/var/log/win95-x11-setup.log、/tmp/win95-xvfb.log、
  /tmp/win95-x11-app.log。
X11 代理只负责把单个程序嵌进 Win95 窗口，不会取代完整 XFCE 桌面；
两者可以同时使用。

完整 XFCE 桌面
--------------
双击桌面的“切换到 XFCE 桌面”，或开始 → 程序 → “切换到 XFCE 桌面”，
或终端执行 /usr/bin/switch-to-xfce：
· 切换脚本会停止 Win95 桌面，在 tty1 上启动 udev、Xorg 与 XFCE；
  在 XFCE 中注销后自动返回 Win95 桌面。
· 首次切换若缺少 Xorg/XFCE/libinput/udev，会在交互式终端里说明
  需要安装的 Alpine 包，并询问是否执行 apk add。
· 修复“XFCE 能显示但鼠标键盘点不动”：启动前会从 /sbin/udevd、
  /lib/udev/udevd 等实际路径启动 eudev（eudev 的守护进程不在 PATH
  里），再执行 udevadm trigger 和 udevadm settle，让 libinput 拿到带
  ID_INPUT 标记的键盘、鼠标或触摸板。
· 诊断日志：/var/log/xfce.log，包含 /dev/input 列表、每个设备的
  udev 标记、xinput list 与 Xorg 的输入相关错误。
· 微信、Firefox 等程序在 XFCE 中同样可以使用；Win95 的 X11 代理
  不需要为完整桌面让路。

微信与 Arch 子系统
------------------
· 开始 → 程序 → 微信 WeChat：首次自动安装 Arch Linux ARM（glibc）、
  官方 ARM64 微信和运行库，然后显示在 X11 嵌套代理窗口中。
· 安装包 /var/cache/win95/WeChatLinux_arm64.deb 在 Alpine 侧，
  chroot 看不到；安装器会先复制到 /opt/archlinux/tmp，再在 chroot 内
  用 bsdtar 解压到 /opt/wechat。
· 若手动解压后报 libandromeda.so 找不到：
  1) 先运行 win95-arch-mounts（否则 /run、/tmp/.X11-unix 不会挂进
     chroot，X11 与 DBus 也连不上）；
  2) pacman -S --needed patchelf libarchive xz nss alsa-lib libxss
     libxtst libxkbcommon-x11 xcb-util-cursor xcb-util-image
     xcb-util-keysyms xcb-util-renderutil xcb-util-wm qt5-base
     qt5-svg qt5-x11extras gtk3 glib2 fontconfig freetype2
     ttf-dejavu noto-fonts-cjk；
  3) 进入 /opt/wechat，把所有嵌套 .so 链接到主程序旁，对主程序和
     .so* 执行 patchelf --clear-execstack 与
     patchelf --set-rpath '$ORIGIN:$ORIGIN/lib:$ORIGIN/lib64:/opt/wechat'；
  4) echo /opt/wechat > /etc/ld.so.conf.d/wechat.conf && ldconfig；
  5) ldd /opt/wechat/wechat | grep 'not found' 应没有输出。
· 运行微信需要 DISPLAY=:1、XDG_RUNTIME_DIR=/run/user/0、
  DBUS_SESSION_BUS_ADDRESS=unix:path=/run/user/0/bus；从桌面
  “微信 WeChat”启动会自动设置这些变量。

多控制台
--------
· Ctrl+Alt+F1 返回 Win95 桌面（tty1）。
· Ctrl+Alt+F2 / Ctrl+Alt+F3 进入文本控制台 tty2 / tty3，
  按一次回车得到 root shell，输入 exit 返回等待状态。
· 也可以在终端中执行 chvt 2、chvt 1 切换控制台。
  切走时桌面会自动关闭 /dev/fb0，切回时自动恢复画面。
· 完整 XFCE 桌面运行在 tty1；切到 XFCE 期间不要再用 chvt 抢占 tty1。
· 文本控制台仅用于排障；单个 X11 程序也可以在嵌套代理中运行。

彩蛋
----
“开始 → 设置 → 危险操作…”会模拟一次经典的 Windows 95 蓝屏，
约 1 秒后按任意键即可返回桌面。这不会损坏系统或文件。

开始菜单中的红色“死手系统（核反击）…”是另一个模拟彩蛋：
· 输入四位授权密码 0000，点击“授权”。
· 出现 10 秒发射倒计时，可按“取消发射”中止。
· 不取消时，全屏闪红约 1.6 秒，然后显示经典蓝屏
  “System Override: Nuclear Strike Confirmed.”。
· 按任意键返回桌面；不会关机，也不会丢失任何文件。

提示
----
· 双击桌面图标可以打开程序。
· 窗口右上角按钮可以最小化、最大化或关闭窗口。
· 拖动标题栏可以移动窗口，拖动右下角可以调整大小。
· 双击标题栏可在最大化和还原之间切换，Alt+F4 关闭当前窗口。
· 在任务栏空白处右键，可以快速整理所有已打开的窗口。
· 在终端中输入 exit 可以关闭当前 shell。
