欢迎使用 Windows 95 Linux 中文版！

这是一个运行在 ARM64 / UEFI 虚拟机中的图形 Linux 系统。
整个桌面直接绘制在 framebuffer 上，不需要 X11 或 Wayland。

桌面功能
--------
· 开始菜单：程序、文档、设置、注销、重新启动、关闭计算机
· 任务栏系统托盘：实时显示 CPU 与内存占用率
· 终端：BusyBox ash，支持中文显示、颜色和常用命令
· 记事本：新建、打开、保存文本文件，支持选择、复制和粘贴
· 计算器：标准四则运算与百分比
· 日历：查看日期
· 文件管理器：浏览 /root 与系统目录
· 网络浏览器：浏览本地 HTML、访问互联网、下载文件
· 扫雷：左键翻开、右键插旗，提供初级/中级/高级三档
· 纸牌：经典 Klondike 接龙，支持拖拽、双击收牌、撤销和计时
· 画图：铅笔、画刷、橡皮、直线、矩形、椭圆，另存为 BMP
· 图形化下载器：输入网址即可下载，带进度、速度与完成提示
· 软件包管理器：搜索、安装、卸载 Alpine 软件包
· 显示属性：6 种桌面背景，以及变幻线、星空、飞行窗口三种屏保
· 运行：输入程序名、路径或网址直接打开，支持历史命令
· 查找：按名称在指定文件夹中搜索文件，可包含子文件夹和隐藏文件
· 回收站：可一次清空全部已删除项目
· 双桌面：一键在 Win95 与 XFCE 之间切换
· XFCE 应用：双击“XFCE 终端”或“Firefox”，在 tty2 后台启动，退出后自动返回
· 通知气泡：截图、下载完成和 XFCE 事件会显示在任务栏右下角
· 网络指示灯：任务栏右下角绿灯表示在线，红灯表示断网
· 屏幕截图：按 Print Screen，或使用“开始 → 设置 → 截屏”
· 文件拖放：把文件从文件管理器拖到回收站，或拖到桌面创建快捷方式
· 鼠标右键菜单：桌面、图标、窗口和任务栏均可右键操作
· 睡眠：开始菜单可让系统进入睡眠，按键或鼠标唤醒
· 彩蛋：“死手系统”核反击模拟与经典蓝屏

鼠标右键菜单
------------
在桌面、图标、窗口标题栏和任务栏上单击右键，都会弹出对应的菜单：
· 桌面空白处：排列图标、刷新、新建、属性（打开显示属性）。
· 桌面图标：打开、资源管理器、重命名、删除、属性。
  回收站图标另有“清空回收站”。
  “我的电脑”等系统图标不能重命名或删除。
· 窗口标题栏：还原、移动、大小、最小化、最大化、关闭。
  也可以按 Alt+Space 打开这个窗口菜单。
· 任务栏：开始按钮、任务按钮、时钟、托盘和空白区域各有菜单。
  空白区域可以层叠窗口、横向平铺、纵向平铺或最小化所有窗口。
菜单支持键盘操作：方向键选择，Enter 确认，Esc 关闭。

桌面文件操作
------------
桌面会显示 /root/桌面 中的真实文件和文件夹，双击即可打开。
· 新建：右键桌面 → 新建 → 文件夹 / 文本文档。
· 重命名：选中图标后按 F2，或右键选择“重命名”。
· 删除：选中后按 Delete，文件会被移到 /root/.trash 回收站。
· 属性：查看文件路径、类型、大小和修改时间。
· 拖放：在文件管理器中按住文件拖到回收站图标、回收站窗口，
  或拖到桌面空白处。拖到回收站会删除文件，拖到桌面会创建
  名为“原名 - 快捷方式”的快捷方式。
· 排列：拖动图标可调整位置；右键桌面可自动排列、对齐到网格、
  按名称排序或按类型排序。
· 刷新：按 F5 或右键选择“刷新”，重新读取桌面文件夹。
桌面快捷键：方向键选择图标，Enter 打开，F2 重命名，Delete 删除，
Ctrl+N 新建文件夹，Esc 取消选择。

系统托盘、显示属性与屏保
------------------------
任务栏右下角显示 CPU 与 RAM 的实时百分比，数据来自
/proc/stat 和 /proc/meminfo，每秒刷新一次。
CPU/RAM 左侧还有网络状态指示灯：绿色表示能连接外网，
红色表示断网，灰色表示正在检测。系统每 12 秒检测一次；
右键托盘选择“网络状态”可以查看详情。

当截图保存、下载完成，或 XFCE 中有事件时，任务栏右下角会
弹出黄色气泡提示，约 8 秒后自动消失；点击气泡右侧的 × 可关闭。

右键桌面选择“属性”，或打开“开始 → 设置 → 显示属性”，可以：
· 在“背景”页选择经典青色、纯青色、海洋蓝、云彩、午夜星空
  或石板灰，右侧显示器会实时预览，确定后立即应用到桌面。
· 在“屏幕保护程序”页选择“无”“变幻线”“星空”或“飞行窗口”，
  并把等待时间设为 1 到 120 分钟。点击“预览”可全屏查看，
  移动鼠标或按任意键返回。设置保存在
  /root/.config/win95/desktop.json，下次启动仍然有效。
  “飞行窗口”是满屏的小 Win95 窗口从中心向四周飞散的 3D 效果。

运行与查找
----------
开始菜单中新增了两个实用工具：
· 运行：输入 calc、notepad、cmd、explorer、iexplore、
  pkgman、control 等命令，或输入文件路径、文件夹路径、网址。
  例如输入 example.com 会直接用浏览器打开。按 ↑ / ↓ 可以
  调出最近使用过的命令；点击“浏览”可以选择文件。
· 查找：在“名称”中输入关键字（支持 * 和 ? 通配符），
  选择搜索范围和是否包含子文件夹/隐藏文件，点击“开始查找”。
  结果会在后台逐步列出，可以随时停止；双击结果即可打开文件
  或进入文件夹。

清空回收站
----------
删除的文件和桌面项目会移到 /root/.trash。右键回收站图标选择
“清空回收站”，或者在回收站窗口中打开“文件 → 清空回收站”，
确认后即可永久删除其中的全部项目。

纸牌
----
开始 → 程序 → 纸牌，规则与 Windows 经典纸牌（Klondike）相同：
· 右上角四个接龙堆从 A 到 K 按花色收牌。
· 下方七列按红黑交替、点数递减堆叠；空列只能放 K。
· 点左上角牌堆发三张牌，发完后点空牌堆重新发牌。
· 拖动牌可以移动；双击一张顶牌会自动送到接龙堆。
· “游戏 → 撤销”（Ctrl+Z）可回退，“发新牌”（F2）重开一局。
· 状态栏显示得分、时间和步数，全部收完会弹出胜利提示。

实用工具
--------
· 截屏：按 Print Screen，或“开始 → 设置 → 截屏”。当前画面
  会保存为 /root/下载/截图-年月日-时分秒.png，并弹出提示气泡。
  请先点一下 UTM 窗口，确保按键送进虚拟机。
· 图形化下载器：开始 → 程序 → 图形化下载器。输入 http:// 或
  https:// 地址（省略协议会自动补 https://），点“开始下载”。
  文件保存在 /root/下载，显示进度、已下载大小和速度；可随时取消。
  下载完成后会弹出气泡提示。
· PC 喇叭提示音：开机与错误对话框会尝试通过控制台响铃。
  UTM / Apple 虚拟化不一定提供 PC 喇叭，听不到声音属于正常现象。

剪贴板
------
记事本与终端共用同一个系统剪贴板：
· 记事本：Ctrl+C 复制、Ctrl+X 剪切、Ctrl+V 粘贴，
  也可以按住鼠标拖动选择文本。
· 终端：Ctrl+Shift+C 复制、Ctrl+Shift+V 粘贴。
· 切换到 XFCE 后剪贴板仍然有效：两边的文本通过
  /run/win95-clipboard 同步。在 XFCE 中复制的内容，
  切回 Win95 后也能直接粘贴。
XFCE 会话会自动启动剪贴板守护进程 win95-clipd。

软件安装与快捷方式
------------------
本系统基于 Alpine Linux（musl），自带 apk 包管理器。
默认使用清华大学 TUNA 镜像（mirrors.tuna.tsinghua.edu.cn）。
打开“开始 → 程序 → 软件包管理器”，先点“刷新”下载软件源索引，
然后输入英文名称搜索并安装。也可以在终端中直接使用：
    apk update
    apk add 软件名
安装完成后，若软件带有图形桌面入口，系统会自动在 /root/桌面
生成快捷方式，双击即可使用（X11 程序会自动切换到 XFCE 启动）。
卸载软件时，自动生成的快捷方式也会一并删除。
注意：Arch/glibc 的软件包不能安装在本系统上。
若镜像不可用，编辑 /etc/apk/repositories 可切换回官方源。
画图保存的 BMP 文件默认放在 /root/图片 文件夹。

网络
----
系统启动时会通过 DHCP 自动获取地址。
如果网络不可用，请检查虚拟机的网卡设置。
浏览器下载的文件保存在 /root/下载 文件夹。

睡眠
----
打开“开始 → 睡眠(S)…”，确认后桌面会先显示深蓝色的睡眠画面，
再让系统进入睡眠以节省电力。按任意键或移动鼠标即可唤醒，
醒来后会提示“系统已从睡眠中唤醒”。
系统会优先使用内核的 freeze（suspend-to-idle）状态，其次尝试
mem（挂起到内存）。是否真正暂停虚拟机取决于 UTM / Apple 虚拟化
对系统睡眠的支持；如果当前内核或虚拟机不支持，系统会弹出错误
提示并留在桌面，不会影响正在编辑的文件。
安装程序运行期间不能进入睡眠。

关机、重启与注销
----------------
开始菜单底部的三个选项都会先弹出 Win95 风格的确认框：
· 关闭计算机：安全关机（poweroff）。
· 重新启动：重启（reboot）。
· 注销：结束当前桌面并返回文本登录提示，按回车可重新进入桌面。

多控制台与 XFCE
---------------
· Ctrl+Alt+F1 返回 Win95 桌面（tty1）。
· Ctrl+Alt+F2 / Ctrl+Alt+F3 进入文本控制台 tty2 / tty3，
  按一次回车得到 root shell，输入 exit 返回等待状态。
· 也可以在终端中执行 chvt 2、chvt 1 切换控制台。
  切走时桌面会自动关闭 /dev/fb0，切回时自动恢复画面。
· 一键切换：双击桌面上的“XFCE 桌面”图标，或使用
  “开始 → 设置 → 切换到 XFCE 桌面”。XFCE 桌面上也有
  “切换到 Win95 桌面”图标。从 XFCE 返回时会先保存剪贴板，
  再结束当前图形会话并 chvt 回 tty1。
· 首次使用 XFCE 时会询问是否安装 Xorg/XFCE（约几百 MB），
  输入 y 确认；安装完成后自动启动。在 XFCE 中注销会回到
  Win95 桌面。
· 切换日志：/var/log/switch-to-xfce.log、/var/log/xfce.log、
  /var/log/Xorg.0.log、/var/log/win95gui.log。

XFCE 应用一键启动
-----------------
桌面上的“XFCE 终端”“Firefox”图标，以及“开始 → 程序”中的
“XFCE 终端 (tty2)”“Firefox (tty2)”，可以在不结束 Win95 桌面的
情况下启动一个 X11 程序：
· 系统自动切换到 tty2，启动 Xorg、窗口管理器和该程序。
· 程序关闭后自动切回 tty1，Win95 桌面和原来打开的窗口都还在。
· 同一时间只运行一个应用；已有应用运行时再次启动会给出提示。
· Win95 下载完成、XFCE 下载完成、XFCE 会话结束等事件会在
  切回 Win95 后以气泡提示显示。
· 需要先安装 Xorg 和对应程序。未安装时系统会给出 apk 命令提示。
· 日志：/var/log/win95-xfce-app.log。

彩蛋
----
“开始 → 设置 → 危险操作…”会模拟一次经典的 Windows 95 蓝屏，
约 1 秒后按任意键即可返回桌面。这不会损坏系统或文件。

开始菜单中的红色“死手系统（核反击）…”是另一个模拟彩蛋：
· 输入四位授权密码 0000，点击“授权”。
· 出现 10 秒发射倒计时，可按“取消发射”中止。
· 不取消时，全屏闪红约 1.6 秒，然后显示经典蓝屏
  “System Override: Nuclear Strike Confirmed.”。
· 按任意键返回桌面；不会关机，也不会丢失任何文件。

提示
----
· 双击桌面图标可以打开程序。
· 窗口右上角按钮可以最小化、最大化或关闭窗口。
· 拖动标题栏可以移动窗口，拖动右下角可以调整大小。
· 双击标题栏可在最大化和还原之间切换，Alt+F4 关闭当前窗口。
· 在任务栏空白处右键，可以快速整理所有已打开的窗口。
· 在终端中输入 exit 可以关闭当前 shell。
