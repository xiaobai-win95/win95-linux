Windows 95 Linux 中文版

一个完全由 Go 编写的 Win95 风格图形环境，直接使用 Linux framebuffer，不需要桌面环境或显示服务器。

系统组成

  • 内核：Linux LTS（ARM64）
  • 固件：UEFI + systemd-boot
  • 根文件系统：ext4
  • 图形界面：自绘 framebuffer UI
  • 终端：BusyBox ash + PTY
  • 浏览器：内置 HTML 排版与 HTTP/HTTPS 支持

安装方式

从安装盘启动，选择一块空白磁盘，安装程序会自动建立 GPT 分区、格式化并复制系统。安装完成后从目标磁盘启动即可。
